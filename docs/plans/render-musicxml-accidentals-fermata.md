# Plan: Render Imported Accidentals and Fermatas

**Date:** 2026-09-16
**Goal:** Preserve MusicXML accidental and fermata notation in the score model and render it on the browser grand staff.

## Context

`.musicxml` files enter through `ScoreFileImporter` and `MusicXmlScoreReader`, then become the shared `Score` model. The browser grand staff is generated by `GrandStaffSceneBuilder`. It currently infers accidentals from pitch and key signature, but does not retain explicit MusicXML accidentals, and it has no fermata model or glyph.

## Request

Import the `<accidental>` and note-notation `<fermata>` elements from the supplied transcription, preserve them when saved scores are serialized, and draw their notation glyphs on the generated browser grand staff.

## Plan

### Phase 1: Preserve notation in the score model

- [x] Add typed score accidental and fermata values as optional `ScoreNote` fields.
- [x] Parse the representable MusicXML accidental values and normal upright/inverted fermatas.
- [x] Preserve the new optional fields through saved-score serialization without breaking older version-1 documents.

### Checkpoint: Import contract

- [x] The Ivanovskaya fixture imports three explicit sharps and two fermatas.
- [x] Focused reader and serializer tests pass.

### Phase 2: Render imported notation

- [x] Prefer an explicit imported accidental over key-signature inference.
- [x] Emit upright or inverted fermata glyphs with note-relative clearance.
- [x] Add scene-builder tests for courtesy accidentals and both fermata orientations.

### Checkpoint: Complete

- [x] Focused MusicXML, serializer, and grand-staff tests pass.
- [x] The complete non-integration test suite passes in Release.
- [x] `git diff --check` reports no formatting errors.

## Risks and open questions

- Existing saved-score JSON must remain readable; new notation fields therefore remain optional and the document version stays unchanged.
- MusicXML supports microtonal accidentals and non-normal fermata shapes that the current pitch and glyph systems cannot represent. Those values remain explicit unsupported-format errors instead of being rendered inaccurately.
- The scope is the browser score grand staff used by the web piece-loading flow, not the separate legacy OpenGL renderer.
